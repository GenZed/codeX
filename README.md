# codeX

An interactive, non-linear video essay in p5.js. Made for Workshops in Creative Coding (Goldsmiths, Term 1, 2024).

A short film I shot in 2016 loops in the background: an open landscape with almost no signs or human markers. Each click lays a seven-word phrase over it. The phrase is generated by a Markov chain trained on Susan Sontag's *The Aesthetics of Silence*. The film's open drift mirrors the way the chain drifts from word to word. The work draws on Godard's *Goodbye to Language*. It also takes up Sontag's idea of artists leaving their medium behind, by turning a piece from my earlier film practice into a computational one.

## Controls

- **Click** to generate a new phrase (the first click also starts the film)

## Run it

Serve the folder with any local web server and open `index.html`, for example:

```
python3 -m http.server
```

p5.js 1.7.0 loads from a CDN. `WESTtx_web.mp4` is a 480p web copy of the original film.

## Font

The original piece uses TfL's Johnston typeface, which can't be redistributed, so this repo ships [Cabin](https://github.com/impallari/Cabin) (SIL Open Font License, see `Cabin-OFL.txt`) instead. Cabin is a humanist sans inspired by Edward Johnston's lettering. If `Johnston100 W03 Medium.ttf` is in the folder, the sketch uses it.
